# Isoliner для RustGIS

Расширение RustGIS с инструментами Isoliner. Мы переносим расчёты
модуля QGIS Isoliner на Rust так, чтобы в RustGIS инструмент принимал
те же поля и выдавал те же значения, что в QGIS.

Расширение собрано на крейте `rustgis-kit`. Крейт отвечает за протокол
RustGIS, окно инструмента, перевод градусов в метры и итоги слоями, а
здесь живут только расчёты.

Лицензия Apache 2.0, © 2026 ООО «Информ++».

Порядок работы над расширением - общие правила продуктов Информ++,
`C:\Dev\workplace\RULES.md`.

## Инструменты

| Код | Инструмент | Что делает |
|---|---|---|
| 1.05 | Декластеризация (веса) | Вес каждой пробы обратно локальной плотности сети и декластеризованное среднее |
| 1.06 | Вариограмма | Экспериментальная вариограмма по всем точкам и по группам, подбор модели, две таблицы без геометрии |
| 1.08 | Кросс-валидация вариограммы | Скользящий контроль кригингом, остатки точками, метрики и советы в журнале |
| 1.09 | Кросс-валидация метода | Скользящий контроль кригингом или минимальной кривизной на выборке точек |
| 1.10 | Пример скважин (демо) | Скважины с кровлей, мощностью и содержанием, по флажкам минтип, напор и линия разлома |
| 1.11 | Пример геофизических профилей (демо) | Профили электроразведки с аномалией-пятном или мульда оседаний по турам в охвате слоя |
| 2.05 | Уклон и экспозиция | Уклон и экспозиция по ядру Horn 3x3, два растра той же сетки, что у ЦМР |
| 2.08 | Разделить горизонтали для проверки | Каждая N-я отметка целиком уходит в проверочный набор, поле hold |
| 3.08 | Пример для плотности (демо) | Точки, линии и полигоны с круглой суммарной массой 1000 |
| 4.11 | Образец справочника пластов | Образец Верхнекамского месторождения таблицей, по порядку залегания |
| 4.13 | Содержания по пласту в устьях | Пробы опробования приводятся к интервалам пласта по длине перекрытия и ложатся в точку устья |
| 7.03 | Размерность линий и границ | Фрактальная размерность каждой линии или границы полигона методом циркуля |
| 7.04 | Размерность Минковского | Размерность линий и границ покрытием ячейками, по объектам и по всему слою |
| 7.05 | Пример для фракталов (демо) | Речная сеть, водосбор и береговая линия срединными смещениями |

Перенесены инструменты, которым не нужны растр и отметка Z. Каждый
сверен со всеми прогонами модуля из `fixtures/tool_runs.json`.

В RustGIS у расширения своя вкладка ленты. Группы на ней идут по
номерам модуля (кригинг, топография, анализ, разрез, фракталы), а
вкладку собирает крейт из `product::tab` вместе с разделом `tools`.

Растровые инструменты модуля переносятся командами с окном: 1.02
«Минимальная кривизна» и 2.05 «Уклон и экспозиция». Инструменту
расширения RustGIS растров не даёт, а команда может звать команды
RustGIS. Растр на входе выгружается `share.exportRaster` во временный
GeoTIFF, точки читаются `host.features` в системе слоя, выход пишется
GeoTIFF-ом и добавляется слоем `layer.addData`. Для этого расширение
просит разрешения `files` и `edit`. Чтение и запись GeoTIFF лежат в
`src/geotiff.rs`, команды в `src/raster_cmd.rs`.

Демо 1.10 и 3.08 в модуле выдают ещё и растры истинных полей. Здесь они
пока инструменты, поэтому выходят только векторные слои.

Нужен RustGIS 0.7.0 и новее.

## Как устроено

Описания инструментов и образцы прогонов выгружает модуль QGIS.

- `fixtures/tools.json` содержит поля, подписи, справку и сообщения на двух языках.
- `fixtures/tool_runs.json` содержит прогоны модуля с входом, выходом, журналом и допусками.

Расчёт инструмента лежит в `src/tools/<имя>.rs` и повторяет файл
`grid_isolines/tools/<имя>.py` модуля. Общие части модуля перенесены
в `declus.rs`, `points.rs` и `field_format.rs`. Суммы складываются в
том же порядке, что у NumPy (`numpy.rs`), а строки журнала
форматируются по правилам Python (`pyfmt.rs`), поэтому значения и
журнал совпадают с модулем.

Случайные значения даёт `npy_rng.rs`, повторяющий `np.random.default_rng`
NumPy бит в бит. Демо-инструмент с тем же зерном выдаёт в RustGIS те же
данные, что в QGIS. Таблицы зиккурата в `ziggurat.rs` взяты из
исходников NumPy 2.4.6 (лицензия BSD-3-Clause) сценарием
`tools/gen_zig.py`, эталоны для теста снимает `tools/gen_rng_ref.py`.

Раздел `tools` в `plugin.json` собирается из `tools.json`.

```powershell
$env:ISOLINER_MANIFEST = '1'; cargo test --test manifest
```

## Проверка

```powershell
cargo test
cargo clippy --all-targets -- -D warnings
```

Тест `tests/fixtures.rs` считает заново каждый прогон модуля и сверяет
поля, точки, значения до допуска прогона и журнал слово в слово. Тест
`tests/manifest.rs` сверяет `plugin.json` с `tools.json`, а
`tests/rustgis.rs` шлёт расширению запрос так, как его шлёт RustGIS.
Тест `tests/raster_cmd.rs` подменяет RustGIS и сверяет растры 2.05 бит
в бит с расчётом модуля на вырезке ЦМР, эталон снимает
`tools/gen_slope_ref.py`.

## Ограничения RustGIS 0.7.0

Слои приходят в WGS 84 и без Z, поэтому значение берётся из поля.
Расчёт идёт в метрах зоны UTM, и размеры ячеек отличаются от местной
системы координат на масштаб зоны. HTML-отчёт модуля здесь не пишется,
его цифры уходят в журнал.

RustGIS принимает у инструмента не больше 32 полей. У 1.09 их 37,
поэтому пять дополнительных настроек решателя минимальной кривизны в
окно не выведены (`HIDDEN` в `src/product.rs`), и расчёт берёт для них
умолчания модуля.
