# Isoliner для RustGIS

Расширение RustGIS с инструментами Isoliner. Мы переносим расчёты
модуля QGIS Isoliner на Rust так, чтобы в RustGIS инструмент принимал
те же поля и выдавал те же значения, что в QGIS.

Расширение собрано на крейте `rustgis-kit`. Крейт отвечает за протокол
RustGIS, окно инструмента, перевод градусов в метры и итоги слоями, а
здесь живут только расчёты.

Порядок работы над расширением — общие правила продуктов Информ++,
`C:\Dev\workplace\RULES.md`.

## Как устроено

Описания инструментов и образцы прогонов выгружает модуль QGIS.

- `fixtures/tools.json` содержит поля, подписи, справку и сообщения на двух языках.
- `fixtures/tool_runs.json` содержит прогоны модуля с входом, выходом, журналом и допусками.

Расчёт инструмента лежит в `src/tools/<имя>.rs` и повторяет файл
`grid_isolines/tools/<имя>.py` модуля. Растровые команды живут в
`src/raster_cmd.rs`, чтение и запись GeoTIFF — в `src/geotiff.rs`.
Общие части модуля перенесены в `declus.rs`, `points.rs`,
`field_format.rs`, `numpy.rs`, `pyfmt.rs` и `npy_rng.rs`, поэтому
значения и журнал совпадают с QGIS.

Вкладка ленты собирается в `src/product.rs::tab::TAB`, группировка
инструментов в панели «Инструменты» — в `apply_toolbox_groups`. Номера
и названия групп совпадают с модулем QGIS.

Раздел `tools` в `plugin.json` перегенерируется тестом:

```powershell
$env:ISOLINER_MANIFEST = '1'; cargo test --test manifest
```

## Проверка

```powershell
cargo test
cargo clippy --all-targets -- -D warnings
```

Тест `tests/fixtures.rs` сверяет каждый прогон модуля, `tests/manifest.rs`
проверяет `plugin.json`, `tests/rustgis.rs` имитирует вызовы RustGIS,
`tests/raster_cmd.rs` сверяет растры бит в бит.

## Ограничения RustGIS 0.8.0

Слои приходят в WGS 84 и без Z, поэтому значение берётся из поля.
Расчёт идёт в метрах зоны UTM, и размеры ячеек отличаются от местной
системы координат на масштаб зоны. HTML-отчёт модуля здесь не пишется,
его цифры уходят в журнал.

RustGIS 0.8.0 принимает у инструмента до 64 полей.

## Упаковка

```powershell
cargo build --release
powershell -ExecutionPolicy Bypass -File ..\rustgis-kit\scripts\package.ps1 `
    -Manifest plugin.json -Program target\release\isoliner-rustgis.exe -Dist dist
```

Установка в RustGIS:

```powershell
rustgis-cli plugins install dist\isoliner-<версия>.rgplugin
```
