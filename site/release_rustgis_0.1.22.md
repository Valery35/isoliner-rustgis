Isoliner для RustGIS 0.1.22 - лента собрана в выпадающие группы.

- Вкладка Isoliner занимает семь групп-меню: «1. Грид», «2. Рельеф», «2. Гидрология», «2. Подготовка», «3. Дополнительно», «9. Оседания» и «Справка».
- В каждой группе один выпадающий список с командами раздела. Значки команд ленту больше не занимают.
- Команды и инструменты не менялись: 22 растровые команды в меню и 13 векторных инструментов в панели «Инструменты» по разделам QGIS.
- Растровые результаты - GeoTIFF float32 в системе координат слоя, nodata -9999.
- Нужен RustGIS 0.8.0 и новее, Windows.

## Установка

1. Скачать `isoliner-0.1.22.rgplugin`.
2. В RustGIS открыть вкладку «Модули» и нажать «Установить из файла».
3. Выбрать пакет и подтвердить установку. Прежнюю версию пакет заменяет.

---

Isoliner for RustGIS 0.1.22 - the tab is grouped into drop-downs.

- The Isoliner tab now holds seven menu groups: 1. Grid, 2. Terrain, 2. Hydrology, 2. Preparation, 3. Additional, 9. Subsidence and Help.
- Each group is one drop-down with the commands of its section. Command icons no longer take ribbon space.
- Commands and tools are unchanged: 22 raster commands in menus and 13 vector tools in the Tools pane by QGIS sections.
- Raster outputs are float32 GeoTIFF in the layer CRS, nodata -9999.
- Needs RustGIS 0.8.0 or later, Windows.

## Install

1. Download `isoliner-0.1.22.rgplugin`.
2. In RustGIS open the Plugins tab and press Install from file.
3. Choose the package and confirm. The package replaces the previous version.
