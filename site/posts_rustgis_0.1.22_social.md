## Русский (ВК, Facebook, Telegram)

Isoliner для RustGIS 0.1.22 - лента по группам

Вкладка Isoliner больше не занимает ленту десятками кнопок. Семь групп-меню: Грид, Рельеф, Гидрология, Подготовка, Дополнительно, Оседания и Справка. В каждой группе один выпадающий список с командами раздела, 22 растровые команды на месте. Векторные инструменты по-прежнему лежат в панели «Инструменты» по разделам QGIS.

Нужен RustGIS 0.8.0 и новее, пакет для Windows.

## English (LinkedIn, Mastodon)

Isoliner for RustGIS 0.1.22 - ribbon by groups

The Isoliner tab no longer fills the ribbon with dozens of buttons. Seven menu groups: Grid, Terrain, Hydrology, Preparation, Additional, Subsidence and Help. Each group is one drop-down with the commands of its section, all 22 raster commands are there. Vector tools stay in the Tools pane by QGIS sections.

Needs RustGIS 0.8.0 or later, Windows package.
