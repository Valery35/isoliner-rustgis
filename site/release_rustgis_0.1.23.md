# Isoliner для RustGIS 0.1.23

Группы на вкладке ленты и в панели инструментов приведены в точное
соответствие с модулем QGIS: `1. Гриды и кригинг`, `2. Топография`,
`2. Топография: диагностика`, `3. Дополнительные инструменты`, `4. Разрез`,
`5. Геологическая модель`, `6. Гидрология`, `7. Фрактальный анализ`,
`8. Обмен файлами`, `9. Оседания`.

Команда `about` теперь выводит уведомление с версией расширения и
количеством инструментов.

Добавлен `doc/NOT_IMPLEMENTED.md` со списком нереализованных инструментов
модуля QGIS.

Реализовано 42 инструмента/команды из 79.

## Установка

```powershell
rustgis-cli plugins install isoliner-0.1.23.rgplugin
```

Требуется RustGIS 0.8.0 и новее.
