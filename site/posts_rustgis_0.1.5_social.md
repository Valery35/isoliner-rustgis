## Русский (ВК, Facebook, Telegram)

Isoliner для RustGIS 0.1.5 - 2D кригинг (точки → растр)

В расширении появилась команда 1.01 «2D Kriging (точки → растр)». Выбираешь точечный слой и поле значения, получаешь растр на заданной сетке. Ординарный или простой кригинг с одной структурой вариограммы — тот же метод, что в модуле QGIS Isoliner.

В окне задаются тип кригинга, радиус поиска, число соседей, наггет, модель, вклад, радиус корреляции, азимут и анизотропия. Есть снятие тренда, логарифмирование, растр стандартной ошибки и отсев ураганных проб. Расчёт идёт в метрах системы слоя. Нужен RustGIS 0.7.0 и новее, пакет для Windows.

## English (LinkedIn, Mastodon)

Isoliner for RustGIS 0.1.5 - 2D kriging (points → raster)

The extension now has the command 1.01 2D Kriging (points to raster). Pick a point layer and a value field, get a raster on the computed grid. Ordinary or simple kriging with one variogram structure — the same method as in the QGIS Isoliner plugin.

The dialog sets kriging type, search radius, number of neighbours, nugget, model, sill, correlation range, azimuth and anisotropy. Polynomial detrend, log transform, standard-error raster and outlier clipping are available. Computation runs in the layer's own CRS. Needs RustGIS 0.7.0 or later, Windows package.
